# 주요 결정 기록

- **2026-11-12 의존성 관리는 `pyproject.toml` 하나로** — `requirements.txt` 대신 pyproject에 런타임(PySide6)과 개발용(ruff, pytest) 의존성, ruff/pytest 설정을 모은다. 설치: `pip install -e ".[dev]"`.
- **2026-11-12 Python 3.14.6 사용** — PC에 설치된 버전. PySide6 6.12가 지원한다. 최소 요구는 3.12로 둔다.
- **2026-11-12 설정은 섹션별 JSON(`ConfigStore`)** — 기능마다 섹션을 갖고, 읽을 때 기본값 위에 저장값을 덮는다. 모르는 키는 버려서 설정 스키마가 바뀌어도 안전하다. 파일이 깨지면 `.corrupt`로 백업하고 기본값으로 시작한다. 저장은 임시 파일을 쓴 뒤 교체한다.
- **2026-11-12 위젯 창은 포커스를 받지 않음** — `WindowDoesNotAcceptFocus`와 `WA_ShowWithoutActivating`으로 클릭이나 드래그를 해도 작업 중인 창의 포커스를 뺏지 않는다.
- **2026-11-12 드래그는 직접 구현** — `startSystemMove` 대신 마우스 이벤트로 옮긴다. 포커스를 받지 않는 창에서도 확실히 동작하고, 놓는 시점을 알 수 있어 위치를 저장하기 쉽다.
- **2026-11-12 종료는 트레이로만** — `setQuitOnLastWindowClosed(False)`로 둬서 위젯을 숨겨도 앱이 꺼지지 않게 한다.
- **2026-11-12 프레임은 상태별 폴더의 PNG 여러 장** — 스프라이트 시트 한 장 대신 `assets/<상태>/` 폴더에 프레임 PNG를 넣고 이름 순(자연 정렬)으로 재생한다. AI 도구가 내보내는 프레임을 그대로 넣기 쉽다. 시작할 때 모두 읽어 두고 그릴 때는 다시 읽지 않는다.
- **2026-11-12 애니메이션 타이머는 필요할 때만** — 프레임이 1장이거나 창이 숨겨지면 멈춰서 유휴 CPU를 0에 가깝게 유지한다.
- **2026-11-12 (3.5단계) 그림 값은 폴더의 JSON에** — 프레임 크기, 발끝 기준점(`anchor`), FPS, 걷기 속도, 바닥선, 이동 범위, 기본 배율은 `character.json`과 `room.json`에 둔다. 코드에는 캐릭터 이름을 쓰지 않고, 설정이 비어 있으면 폴더 이름 순 첫 번째를 고른다.
- **2026-11-12 (3.5단계) asset_loader는 Qt 없이** — PNG 크기는 헤더(IHDR)만 읽어 확인한다. 검증 로직을 Qt 없이 테스트할 수 있다.
- **2026-11-12 (3.5단계) 도트는 미리 확대** — 시작할 때 정수 배율로 nearest-neighbor 확대본과 좌우 반전본을 만들어 두고, 그릴 때는 복사만 한다. 캐릭터 위치는 원본 1px 단위로 맞춰 도트가 어긋나지 않게 한다.
- **2026-11-12 (3.5단계) 돌아다니기는 이벤트 기반 타이머** — 걸을 때만 갱신하고, 쉴 때는 쉬기가 끝나는 시점에 한 번만 깨어난다. 위치가 원본 1px 이상 바뀔 때만 다시 그린다.
- **2026-11-12 (7단계) 걷기는 1px마다 깨어남** — 고정 50ms 갱신은 윈도우의 15.6ms 타이머 단위 때문에 61~64ms로 늘어나 2~3px씩 들쭉날쭉했다. 그릴 x가 1px 바뀌는 시각을 계산해 `PreciseTimer`로 깨어나고, 경과 시간은 ns로 잰다. 다시 그리기는 캐릭터 영역만 한다.
- **2026-11-12 (3.5단계) 창은 불투명** — 방 장면과 대화창이 사각형이라 투명 배경(`WA_TranslucentBackground`)을 껐다.
- **2026-11-12 (4단계) 기능↔화면은 `UiBus`로만** — 기능은 ui를 import하지 않고 범용 신호(`show_dialog`, `set_character_state` 등)로 요청한다. 연결은 `app.connect_bus()`가 한다. 버튼과 메뉴 id는 `<기능명>.<이름>`으로 지어 다른 기능의 것은 무시한다. (사용자 승인)
- **2026-11-12 (4단계) 알림 타이머는 단발 하나** — 1초 폴링 대신, 알림 시각과 남은 분 표시가 바뀌는 시각 중 빠른 쪽에만 깨어난다.
- **2026-11-12 (4단계) 알림음은 표준 라이브러리 `winsound`** — 새 의존성 없이 윈도우 기본 알림음을 낸다.
- **2026-11-12 (5단계) 설정 창은 스키마로 자동 생성** — 기능이 `settings_fields()`로 항목을 알리면 설정 창이 입력칸을 만든다. 새 기능을 추가해도 설정 창 코드는 고치지 않는다. 설정이 바뀐 기능만 다시 시작한다. (사용자 승인)
- **2026-11-12 (5단계) 배율은 즉시 적용** — `PikoView`가 방 장면과 대화창을 새 배율로 다시 만들면서 보이던 상태를 옮긴다. 창은 오른쪽 아래 모서리를 기준으로 크기를 바꾼다. (사용자 승인)
- **2026-11-12 (5단계) 창 위치는 드래그가 끝날 때마다 저장** — 비정상 종료에도 위치가 남는다. 복원할 때는 모니터 구성이 바뀌었을 수 있으므로 화면에 충분히 보이는지 확인한다.
- **2026-11-12 (6단계) 자동 실행은 레지스트리 Run 키** — 시작 폴더 바로가기는 만들려면 추가 라이브러리(pywin32 등)가 필요하다. `winreg`(표준 라이브러리)로 `HKCU\...\Run`에 쓴다. 관리자 권한도 필요 없다.
- **2026-11-12 (6단계) 빌드 설정은 `piko.spec`으로 관리** — 명령줄 옵션 대신 spec 파일에 assets 포함, 콘솔 없음, 제외 모듈을 적어 두고 버전 관리에 남긴다.
- **2026-11-12 (7단계) 정면 상태는 반전하지 않음** — `front_facing_states`에 적은 상태는 왼쪽을 볼 때도 반전하지 않는다. 정면 그림을 반전하면 비대칭 소품(머리핀)이 반대로 간다.
- **2026-11-12 (7단계) 자동 실행 경로는 등록된 파일이 없을 때만 고침** — 실행 위치만 다르다고 덮어쓰면 개발용 실행이나 dist 빌드가 설치한 exe의 등록을 빼앗는다.
- **2026-11-12 (8단계) 알림 겹침은 `AttentionCoordinator`로** — 기능끼리 import하지 않고 우선순위(스트레칭 20 > 허리 10)로 화면 차지를 조율한다. 낮은 쪽은 차지 못하면 알림 없이 타이머만 다시 시작하고, 떠 있다가 밀려나면 닫고 다시 시작한다. (사용자 승인)
- **2026-11-12 (8단계) 타이머 패널은 끌어오기(pull)** — 기능이 `timer_entries()`로 남은 시간을 주고, 패널이 펼쳐져 있을 때만 1초마다 읽는다. 접혀 있으면 타이머도 그리기도 없다. 새 기능은 이 메서드만 구현하면 패널에 나온다. (사용자 승인)
- **2026-11-12 (8단계) 캐릭터 상태는 후보 목록** — 기능이 `["stretch", "alert"]`처럼 보내면 캐릭터에 있는 첫 상태를 쓴다. 전용 모션 폴더를 추가하면 코드 수정 없이 반영된다.
- **2026-11-12 (8단계) 메뉴바·패널은 배율과 무관한 고정 크기** — 방과 대화창만 배율을 따른다. 기본 배율이 1이 되어 지금은 차이가 없다.
- **2026-11-12 스마트 앱 컨트롤 때문에 pythonw 바로가기 방식으로 배포** — 윈도우 11 스마트 앱 컨트롤이 서명 없는 PyInstaller `Piko.exe`를 차단한다. 코드 서명 인증서 없이 해결하려고, 서명된 `.venv\Scripts\pythonw.exe`로 `main.py`를 실행하는 `Piko.lnk`(피코 아이콘, 콘솔 없음)로 배포한다. 자동 실행도 레지스트리 Run 키 대신 시작 프로그램 폴더에 같은 바로가기를 둔다(예전 Run 등록은 실행 시 옮기고 지움). `piko.spec` 빌드는 나중을 위해 남겨 둔다. 이 결정으로 위의 "(6단계) 자동 실행은 레지스트리 Run 키"를 대체한다. (사용자 요청)
- **2026-11-12 바로가기는 PowerShell의 WScript.Shell로** — pywin32 같은 새 라이브러리 없이 `.lnk`를 만들고 읽는다. 경로는 환경 변수로 넘겨 한글·공백 경로의 따옴표 문제를 피하고, `CREATE_NO_WINDOW`로 콘솔을 띄우지 않는다.
- **2026-11-12 설정 창은 모달이 아님** — `exec()`는 위젯 창 입력을 막아 설정 중에 타이머 패널을 볼 수 없었다. `show()`로 띄우고 [저장](`accepted`)에서 적용한다. 이미 열려 있으면 앞으로 가져온다.
- **2026-11-12 `Feature`는 QObject를 상속하지 않는 ABC** — 로직을 Qt 없이 테스트하기 위해서다. 기능이 시그널이 필요하면 내부에 QObject를 둔다.
